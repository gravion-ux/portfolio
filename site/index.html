// 01 — about

Proof, not promises

I'm a penetration tester and offensive security analyst based in Delhi, India, working remotely with Sentra Byte Digital Solusi since December 2025, and a freelance security analyst since March 2024. My work centres on the OWASP Top 10 and OWASP API Security Top 10: authorisation flaws (BOLA and IDOR), broken authentication and session handling, injection, and business logic that fails under pressure — reported so engineers can actually act on it.

Alongside client work I build and maintain 46 open-source projects — from WordPress CVE hunting to LLM red-teaming and MCP config auditing — and I contribute fixes upstream to the projects I use, including merged pull requests to xerj-org/xerj. In November 2026 my first bug-bounty report — a sensitive-data exposure in a major WordPress events plugin, verified in a local lab and dedupe-checked — was filed with Patchstack. My current flagship build is Gravion AI, a modular AI platform that startups can adopt instead of starting from scratch.

In 2026 I also completed a research internship at azmth on post-quantum security — CRYSTALS-Kyber / ML-KEM and CRYSTALS-Dilithium in practice, not just on paper.

  1. Read the code path first, before running tools.
  2. Reproduce the bug with the smallest possible proof.
  3. Quantify impact in terms the business cares about.
  4. Write the fix as a code suggestion, not just an observation.
  5. Measure before and after — quote only numbers a command produced.
